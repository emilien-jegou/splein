
# [riode_shader] examples

This folder contains examples of how to use [riode_shader] in your applications:

- `riode_shader_wgpu` a library-crate example of how to integrate [riode_shader] with [wgpu], which
    is used by other examples in this folder
- `hello_triangles` a windowed application that draws a stack of spinning triangles with blending

[riode_shader]: https://github.com/raymarch/riode_shader
[wgpu]: https://crates.io/crates/wgpu
[winit]: https://crates.io/crates/winit

## riode_shader/wgpu integration
For a quick start with [riode_shader] in your own [wgpu] project, you can use the example integration `riode_shader_wgpu` directly.
